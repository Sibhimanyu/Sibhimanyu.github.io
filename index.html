  • RasanAI

    Claude Code skill · AI video

    AI video director for Claude Code. Pick one of three complete films and Claude designs, animates and renders it: launch films, explainers, reels from your footage, motion graphics. Built on HyperFrames.

    Visit site →GitHub

  • Flotilla

    Multiplayer agentic app builder

    Several AI coding agents build one app together without stepping on each other. Each teammate runs their own agent; Flotilla hands out tasks, enforces who may touch which files, and shows one live board.

    Visit site →GitHub

  • Heresay

    Feedback that reaches your coding agent

    In-app feedback and bug reports for web, iOS and macOS apps. Your team accepts each report; accepted ones go to your coding agent (Claude Code, Cursor, Codex) over MCP. Self-hosted on Firebase.

    Visit site →GitHub

  • Greenroom

    macOS · one-click classroom

    A macOS app that sets up a whole morning class in one click: OBS virtual camera, Zoom and a tiled layout. Built for a reading class at Zoho Schools.

    Visit site →GitHub

  • Imago

    API responses as interfaces

    APIs become interfaces. Paste an API URL or a curl command, and Imago reads the JSON's shape and draws a live interface for it. Browser-only, no build step.
